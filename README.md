# Hello World

A simple Python hello world script demonstrating basic project structure with source code in `src/` and tests in `tests/`.

## Requirements

- Python 3.x

## Project Structure

```
src/        # Source code
tests/      # Test suite
```

## Usage

Run the hello world script:

```bash
python src/hello.py
```

Expected output:
```
Hello World
```

## Running Tests

```bash
pytest
```
